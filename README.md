<h1 align="center">青简 Qingjian</h1>

<p align="center"><strong>好好输入，顺便多认识一个词。</strong></p>


基于原版分支，自定义护眼绿主题、调整设置界面、双语译文同显、增加多项字体设置、译文熟词变灰功能开关、去掉浮窗背景使其能贴边、支持更多词库格式导入等修改；
修正候选窗失焦不关闭遮挡界面、输入焦点跟随异常等问题。

* 仅针对Windows平台。
